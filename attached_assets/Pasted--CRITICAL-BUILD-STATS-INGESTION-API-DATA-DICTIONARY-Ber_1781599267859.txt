[CRITICAL BUILD: STATS INGESTION API & DATA DICTIONARY]
Bertindaklah sebagai Senior Backend Engineer. Ekstensi Chrome kita sudah siap mengirimkan data statistik dalam bentuk JSON. Sekarang kita harus membangun endpoint penerima dan menanamkan "Kamus Konteks Statistik" agar AI (Gemini) nanti bisa memahami arti dari setiap laci JSONB di database kita.

TUGAS 1: PERSIAPAN ENDPOINT & API KEY
Buat sebuah route POST /api/stats/ingest.

Wajibkan adanya header x-api-key.

Bandingkan nilainya dengan environment variable process.env.EXTENSION_API_KEY.

Jika tidak valid atau tidak ada, tolak dengan status 401 Unauthorized.

Kembalikan URL endpoint lengkap dan instruksi pembuatan API Key di balasan Anda agar saya bisa memasukkannya ke ekstensi.

TUGAS 2: STRUKTUR JSONB PAYLOAD YANG DIHARAPKAN
Endpoint ini harus siap menerima JSON dengan struktur eksak seperti ini:

JSON


{
  "raw_url_path": "england/premier-league",
  "stat_type": "stats_xg",
  "season": "2025-26",
  "teams": [
    {
      "raw_team_name": "Manchester United",
      "stat_data": { "MP": "38", "xG": "1.74", "xGA": "1.36", "xGD": "+0.38" }
    }
  ]
}
Normalisasikan raw_url_path menjadi format slug (misal: england-premier-league). Lalu lakukan UPSERT ke tabel team_season_stats di Supabase. INGAT: Hanya perbarui kolom yang sesuai dengan stat_type yang dikirim, jangan timpa kolom statistik lain dengan null.

TUGAS 3 & 4: PEMBUATAN KAMUS STATISTIK (DATA DICTIONARY)
